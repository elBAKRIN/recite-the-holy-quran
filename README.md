## 📝 وصف المشروع

**القرآن الكريم** تطبيق محمول مبني بـ **Flutter** يساعد المسلم على حفظ كتاب الله ومراجعته.
يجمع التطبيق بين قراءة المصحف برسمٍ عثمانيّ، والاستماع لتلاوات نخبة من القرّاء،
وتسجيل تلاوة المستخدم لمقارنتها ومراجعتها، إضافةً إلى متابعة ختمة منظَّمة، وإذاعة
قرآنية تعمل في الخلفية، وتفسيرٍ ميسَّر للآيات.

المشروع **مجانيّ بالكامل** ولا يحتوي على أيّ إعلانات أو مشتريات داخلية أو اشتراكات،
ويُقدَّم ابتغاء وجه الله ليكون **صدقة جارية**.

## 💡 فكرة التطبيق

الحفظ المتقن يحتاج إلى ثلاثة أركان: **سماعٌ صحيح**، **تكرارٌ منظَّم**، و**مراجعةٌ
ذاتية**. يوفّر التطبيق هذه الأركان في مكان واحد:

1. **اسمع** التلاوة من قارئك المفضّل (آية بآية أو سورة كاملة).
2. **اقرأ** من المصحف العثماني بخطّ حفص أو ورش مع تظليل الآية الحالية.
3. **سجّل** صوتك وأنت تتلو، ثم استمع إليه وقارنه بالتلاوة الأصلية.
4. **علّم** مواضع الخطأ في الآيات لتراجعها لاحقاً.
5. **تابع** ختمتك اليومية وموضع توقّفك تلقائياً.

## ✨ المميزات

### 📖 قراءة المصحف
- عرض المصحف الكامل (114 سورة) بالرسم العثماني.
- روايتان: **حفص عن عاصم** و**ورش عن نافع** (تبديل من الإعدادات).
- عرض صفحات المصحف مع فاصل أرقام الصفحات وتظليل الآية أثناء التشغيل.
- التمرير التلقائي (Auto-Scroll) ووضع ملء الشاشة للقراءة المريحة.
- قائمة منسدلة للآيات (Context Menu) للنسخ والمشاركة والتفسير ووضع علامة خطأ.

### 🎧 الاستماع والتلاوة
- مصدران للصوتيات: **alquran.cloud** و**quran.com (Quran.Foundation)**.
- اختيار من بين عشرات القرّاء المعتمدين، آيةً بآية.
- اختيار جودة الصوت (kbps) للمصدر الأصلي.
- **تنزيل التلاوات** للاستماع دون اتصال بالإنترنت.

### 📻 الإذاعة القرآنية
- بثّ متواصل لسور كاملة بصوت القارئ المختار.
- **يعمل في الخلفية** وعند قفل الشاشة مع إشعار تحكّم (تشغيل/إيقاف/تنقّل).

### 🎙️ تسجيل التلاوة
- تسجيل صوت المستخدم أثناء التلاوة ثم الاستماع إليه ومراجعته.
- إدارة التسجيلات المحفوظة (تشغيل، مشاركة، حذف).

### 🟢 الختمة
- إنشاء خطة ختمة (Khatma) بعدد أيام محدّد وتتبّع التقدّم اليومي.
- قارئ ختمة مخصّص يتزامن مع موضعك المحفوظ.
- إعدادات وسائط الختمة.

### 📚 التفسير والترجمة
- عرض **التفسير الميسَّر** للآيات.
- شاشة ترجمة منفصلة للمحتوى.

### 🔖 أدوات الحفظ والمتابعة
- حفظ آخر موضع قراءة تلقائياً واستئنافه.
- **علامات الأخطاء** (Error Marks) لحفظ مواضع الخطأ ومراجعتها.
- بحث سريع عن السور.

### 🎨 التخصيص واللغات
- ثلاثة أوضاع ألوان: **ورق معتّق**، **زيتوني**، **عسلي**.
- التحكّم في حجم الخط.
- **14 لغة** للواجهة: العربية، الإنجليزية، الأوردية، الإندونيسية، الهندية،
  المليبارية، الفرنسية، الألمانية، الإيطالية، الهولندية، الإسبانية، الولوفية،
  الهوساوية، الصومالية.

### 🔔 أخرى
- إشعارات وتذكيرات (تعتمد على المنطقة الزمنية).
- محتوى التقويم الهجري/الإسلامي.

| التقنية | الدور |
|---|---|

| **shared_preferences** | حفظ الإعدادات والموضع وعلامات الأخطاء محلياً. |
| **path_provider** / **path** | تحديد مسارات تخزين التسجيلات والتلاوات المنزَّلة. |
| **permission_handler** | إدارة أذونات الميكروفون والتخزين والإشعارات. |

## 🚀 التثبيت والتشغيل

### المتطلبات
- **Flutter SDK** متوافق مع `sdk: ^3.8.1` (راجع `pubspec.yaml`).
- Android SDK (مع NDK) و/أو Xcode حسب المنصّة المستهدفة.

### الخطوات

```bash
# 1) استنساخ المشروع
git clone <رابط-مستودعك>.git
cd recite_the_holy_quran

# 2) تثبيت الاعتماديات
flutter pub get

# 3) (اختياري) تهيئة مفاتيح quran.com — راجع القسم التالي

# 4) التشغيل
flutter run
```

> يعمل التطبيق مباشرةً بدون أيّ مفاتيح، معتمداً على مصدر **alquran.cloud**.

## 🔑 إعداد المفاتيح

التطبيق يعمل **افتراضياً** بمصدر **alquran.cloud** دون أيّ إعداد. مصدر
**quran.com (Quran.Foundation)** **اختياري ومُعطَّل ما لم تضبط مفاتيحك الخاصّة**
(لا توجد أيّ مفاتيح مُضمّنة في الشيفرة). تُقرأ المفاتيح حصراً وقت البناء عبر
`--dart-define=QF_CLIENT_ID` و `--dart-define=QF_CLIENT_SECRET`، وعند غيابها
يُعطَّل مصدر quran.com تلقائياً ويظهر إشعار داخل التطبيق (أعلى صفحة القرّاء)
ينبّه المبرمج/مَن يُعيد البناء بضرورة ضبط المفاتيح.

> 🛑 **لتفعيل مصدر quran.com:**
> سجّل تطبيقك على
> [api-docs.quran.foundation](https://api-docs.quran.foundation/) واحصل على
> مفاتيحك الخاصّة، ثم مرّرها وقت البناء:

```bash
flutter build apk --release \
  --dart-define=QF_CLIENT_ID=ضع_معرّفك \
  --dart-define=QF_CLIENT_SECRET=ضع_سرّك
```

أو عبر ملف (انسخ `env.json.example` إلى `env.json` واملأه — وهو مُستبعَد من Git):

```bash
flutter run --dart-define-from-file=env.json
```

⚠️ **تنبيه أمني:** أيّ `client_secret` يُمرَّر إلى تطبيق عميل قابل للاستخراج
نظرياً. الحماية الكاملة لـ `client_secret` تكون بوضعه خلف خادم وسيط (proxy).
راجع [`SECURITY.md`](SECURITY.md).

## 🔊 مصادر الصوتيات

1. **alquran.cloud** — عبر شبكة `cdn.islamic.network` (آية بآية، عدّة مستويات
   جودة). المصدر الافتراضي.
2. **Quran.Foundation / quran.com** — عبر `verses.quran.com` و
   `apis.quran.foundation` (آية بآية وسور كاملة). اختياري بمفاتيح.

> حقوق التلاوات الصوتية تعود لأصحابها ومصادرها. هذا المشروع يستهلك هذه المصادر
> عبر واجهاتها العامة ولا يدّعي ملكيتها.

## 📜 مصادر التفاسير والنصوص

- **نصّ المصحف والرسم العثماني** (روايتا حفص وورش) والخطوط: من مصادر مجمّع الملك
  فهد لطباعة المصحف الشريف / موارد quran.com العامة (`assets/quranjson`,
  `assets/fonts`).
- **التفسير الميسَّر** (`assets/hafs_tafseerMouaser_v3`).

> ⚠️ **مهم:** النصوص والخطوط والتفاسير القرآنية قد تخضع لتراخيص خاصّة بمصادرها
> الأصلية. هذه الرخصة (FISAL) تحكم **كود المشروع فقط** ولا تُسقط حقوق أصحاب تلك
> المصادر. على أيّ مُعيد نشر التحقّق من تراخيص هذه الأصول بنفسه قبل النشر.

## ⚖️ الترخيص وقواعد إعادة النشر

هذا المشروع مرخّص تحت **رخصة المصدر الإسلامي الحر (FISAL)** — رخصة **متاحة المصدر
وغير تجارية**. راجع ملف [`LICENSE`](LICENSE).

**يُسمح:** بالاستخدام المجاني، التعلّم، التعديل، التطوير، والأعمال المشتقّة.

**يُمنع:** البيع، الإعلانات، المشتريات داخل التطبيق، الاشتراكات المدفوعة، وأيّ
استخدام تجاري أو ربح مباشر/غير مباشر.

### 🔁 قواعد إعادة النشر (إلزامية)
أيّ شخص يريد إعادة نشر التطبيق **يجب** عليه أولاً تغيير:
- اسم التطبيق.
- اسم الحزمة (Android `applicationId`).
- مُعرّف الحزمة (iOS `Bundle Identifier`).
- مشروع Firebase ومفاتيح الخدمات (إن وُجدت).
- توقيع التطبيق (Keystore).
- إعدادات النشر وبيانات التواصل.

ولا يجوز إعادة نشر التطبيق **بنفس الهوية الأصلية**، مع وجوب **الإشارة إلى المشروع
الأصلي والمطوّر الأصلي**. خطوات التفصيل في [`OPEN_SOURCE_GUIDE.md`](OPEN_SOURCE_GUIDE.md).
